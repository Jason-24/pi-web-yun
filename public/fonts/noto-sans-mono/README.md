# Noto Sans Mono

Variable WOFF2 files and Unicode ranges from
`@fontsource-variable/noto-sans-mono@5.3.0` (`wght.css`, weight 100–900).
The seven subsets retain Latin, Cyrillic, Greek and Vietnamese coverage.

Source: https://fontsource.org/fonts/noto-sans-mono
Upstream: https://github.com/notofonts/latin-greek-cyrillic
License: SIL Open Font License 1.1; see OFL.txt in this folder.

These files are checked in so builds do not contact Google Fonts.
The matching font faces, fallback metrics and CSS variable live in
`app/fonts.css`. The root layout preloads Latin and Cyrillic, as before.
