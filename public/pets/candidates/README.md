# Independent character candidate

This is a review asset, not the active companion. The face, straight hair and outfit differ from the user's reference, so it must not be silently substituted for the desired character.

`lin-yue-candidate.glb` was configured and exported from the public CharacterCreator viewer at https://dionysus.dk/webxr/charactercreator/ using the project's published export interface. Source: https://github.com/kblood/CharacterCreator ; asset provenance and dedication: https://github.com/kblood/CharacterCreator/blob/master/LICENSE-NOTES.md .

The exported file's own `asset.copyright` identifies the MakeHuman meshes, textures, rig, hair and clothing, and the generated export geometry/textures as CC0 1.0. It has one shared 53-joint skeleton, baked female body proportions, embedded PBR textures, and 12 fitted animation clips. No upstream GPL runtime source is included in this application. Preview rendering code is written locally using the existing three.js dependency.

Only the idle clip is played by the review page. The viewer supports free rotation and zoom. This model is a candidate for discussion; it does not reproduce the reference person's identity.
