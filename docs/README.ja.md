# PI-YUN

PI-YUN は [Pi Web](https://github.com/agegr/pi-web) をベースにした、[pi コーディングエージェント](https://github.com/earendil-works/pi)のブラウザー向けワークスペースです。会話やプロジェクトの管理に加え、サイドチャット、コンパニオン、集中タイマーを利用できます。

Node.js 22.19.0 以降が必要です。

```bash
npx pi-yun@latest
```

起動後、[http://127.0.0.1:30141](http://127.0.0.1:30141) を開き、設定のモデル画面でプロバイダーを設定してください。グローバルインストールは `npm install -g pi-yun@latest`、起動は `pi-yun` です。

設定、開発、リリースについての最新情報は[メイン README（中国語）](../README.md)を参照してください。上流のデモや Docker イメージは PI-YUN のリリースではありません。
