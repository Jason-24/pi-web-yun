# PI-YUN

PI-YUN — браузерное рабочее пространство для [кодирующего агента pi](https://github.com/earendil-works/pi), основанное на [Pi Web](https://github.com/agegr/pi-web). Оно помогает управлять проектами и сессиями и включает боковые чаты, компаньона и таймер концентрации.

Требуется Node.js 22.19.0 или новее.

```bash
npx pi-yun@latest
```

После запуска откройте [http://127.0.0.1:30141](http://127.0.0.1:30141) и настройте провайдера моделей в настройках. Для глобальной установки выполните `npm install -g pi-yun@latest`, затем запустите `pi-yun`.

Актуальные сведения о настройке, разработке и выпуске находятся в [основном README (на китайском)](../README.md). Демо и Docker-образ исходного проекта не являются релизами PI-YUN.
